# Quick install

Clone this repository directly into ComfyUI's `custom_nodes` folder.

From:

```text
ComfyUI/custom_nodes
```

run:

```bash
git clone https://github.com/Slartibart23/comfyui-lmstudio-qwen35-captioning.git
```

Expected result:

```text
ComfyUI/custom_nodes/comfyui-lmstudio-qwen35-captioning/__init__.py
```

Restart ComfyUI completely.

Do not place this repository inside another `custom_nodes` folder and do not copy only the workflow. ComfyUI must be able to import the root `__init__.py`.
